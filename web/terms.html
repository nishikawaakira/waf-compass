WAF Compass 利用規約

改定日：2026年10月20日

本規約は、西川 彰（以下「運営者」）が提供する WAF Compass（以下「本サービス」）の利用条件を定めます。利用者は、評価を送信する際に本規約に同意します。

1. サービスの内容

本サービスは、利用者が提出した AWS WAF の Web ACL 定義、ModSecurity ルール、またはアクセスログを分析し、説明と結果を返します。アクセスログからは AWS WAF ルール候補を提案します。AWS WAF は定義ファイルの静的なレビューです。ModSecurity は隔離された Apache / ModSecurity 2 環境で固定されたリクエストを試します。利用者の稼働中のアプリケーションにリクエストを送信しません。

2. アカウント、料金、利用制限

評価にはログインが必要です。現時点で評価は無料ですが、1人につき日本時間の1日1回、提出ファイルは1回1 MiB以下です。失敗した評価も当日の利用枠を消費する場合があります。サービス全体の予算や障害により、受付を制限・停止する場合があります。有料機能を開始する場合は、料金と適用条件を別途明示します。

3. 提出内容と権利

利用者は、提出するルールまたはアクセスログについて本サービスでの処理を許可する権限を持つものとします。提出物の権利は利用者または正当な権利者に帰属します。利用者は、評価に必要な範囲で、運営者が提出物を保存、複製、解析し、ルールまたはログから作成した集計情報を Amazon Bedrock に送信することを許諾します。ログには IP アドレスや URL のクエリ文字列など個人情報・秘密情報が含まれ得ます。提出前に不要な情報を削除してください。

4. 禁止事項

他人の権利を侵害する提出、違法な利用、他人のアカウント利用、利用回数やボット対策の回避、サービスや第三者のシステムへの過度な負荷・妨害、評価環境から外部へアクセスさせる試みを禁止します。運営者は、違反が疑われる場合に利用を制限できます。

5. 評価結果の限界

自然言語の説明には生成 AI を使用するため、誤りや見落としがあり得ます。固定ケースの結果は試した条件だけを示します。アクセスログのパターンは攻撃や遮断の証明ではありません。AWS WAF の静的レビューは実際の遮断を確認しません。ルールの有効性、脆弱性の不存在、OWASP Top 10 の網羅、本番環境での同一動作を保証しません。利用者は、本番への適用前に自ら検証してください。

6. 提供の変更・終了と責任

運営者は保守、障害、予算上限その他の必要がある場合、本サービスを変更・中断・終了できます。運営者は合理的な安全対策を講じますが、継続提供や評価結果の完全性を保証しません。損害賠償責任は適用法令で認められる範囲に限られ、運営者の故意または重過失による責任や法令上免責できない責任は除外しません。

7. 規約の変更、準拠法、連絡先

規約を変更する場合は、このページに変更内容と効力発生日を掲示し、重要な変更は適切な方法で通知します。準拠法は日本法とし、本サービスに関する紛争については、法令上許される範囲で鹿児島地方裁判所を第一審の合意管轄裁判所とします。お問い合わせは info [at] i-wind.jp（[at] を @ に置き換えてください）へお願いします。

Revised: October 20, 2026

The Service analyzes submitted AWS WAF Web ACL definitions, ModSecurity rules, or access logs. Access-log analysis suggests AWS WAF rule candidates. AWS WAF analysis is a static review. ModSecurity samples run in an isolated Apache / ModSecurity 2 environment. The Service does not send test requests to your live application.

Sign-in is required to run an evaluation. Evaluations are currently free, limited to one per user per Japan Standard Time day and a 1 MiB file per submission. A failed evaluation may still use that day's allowance. The Operator may limit or suspend submissions for budget or operational reasons. Any future paid feature will have separately disclosed prices and conditions.

Logs may contain IP addresses, URL query strings, personal data, or secrets; remove unnecessary information before submission.
