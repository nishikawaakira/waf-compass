WAF Compass

AWS WAF と ModSecurity のルールを、評価順と固定テストの観点から確認します。

WAF Compass でできること

ルール定義をアップロードし、防ぎたい攻撃の種類を選ぶと、確認結果を日本語または英語の文章で受け取れます。

AWS WAF

GetWebACL の JSON を静的に確認し、ルールの優先順位や設定上の懸念を説明します。実際の遮断は測定しません。

ModSecurity

ルール一式を隔離した Apache / ModSecurity 2 環境で試し、固定の攻撃・正常リクエストの結果を示します。

アクセスログ

WAF 未導入でも、アクセスログを集計して AWS WAF の候補ルールと確認手順を説明します。

ログインして評価を始める

現在は無料で、評価は利用者ごとに日本時間で1日1回までです。利用にはログインが必要です。

使い方

  1. ログインして、AWS WAF または ModSecurity を選びます。
  2. ルールファイルは 1 MiB、アクセスログは 50 MiB 以下で指定します。
  3. 評価結果で、ルールの分析と固定ケースの結果を確認します。

WAF Compass はアプリケーション全体の脆弱性診断ではありません。AWS WAF の結果は静的レビューであり、ModSecurity の測定は固定ケースと隔離環境に限られます。

新しい評価

ルールファイルは 1 MiB 以下、アクセスログは 50 MiB 以下です。

試したい攻撃の種類

固定ケースは主に A01 の SSRF・パストラバーサルと A05 のインジェクションを扱います。その他の Top 10 リスクはアプリケーション側の検証が必要です。 OWASP Top 10:2025

複数選んでも評価は1日1回分です。AWS WAF の静的レビューは実際の遮断確認ではありません。ModSecurity は Apache 用 ModSecurity 2 の隔離環境で固定ケースを測定します。本番が ModSecurity 3 などの場合、動作が異なる可能性があります。OWASP Top 10 全体の網羅やアプリケーションの安全性は証明できません。

ログには IP アドレスや URL のクエリなどが含まれます。不要な情報を削除してからアップロードしてください。分析は候補の提案であり、攻撃や遮断の証明ではありません。候補は Count モードで検証してください。
